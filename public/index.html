ℹ️ About This Project

CodeAlpha AI Internship

The AI Language Translation Tool is an intelligent web application engineered to bridge communication gaps by translating text in real-time across 20+ languages. Developed as part of the CodeAlpha Artificial Intelligence Internship, it is architected with a serverless Python Flask backend and an optimized Edge CDN frontend hosted on Vercel.

🌐

Multilingual Engine

Seamless translation between 20+ languages including major Indian languages (Telugu, Hindi, Tamil, Kannada, Malayalam).

⚡

Vercel Serverless Architecture

Serverless Python backend with Edge CDN static serving for near-instant response times and 99.9% uptime.

🔊

Text-to-Speech Integration

Integrated Web Speech synthesis to listen to native pronunciation in the target language.

🛡️

Validation & Resilience

Real-time 500-byte boundary tracking, duplicate language prevention, and automated fallback error handling.

Python 3.14 Flask Vercel Serverless MyMemory REST API HTML5 & Vanilla CSS JavaScript (ES6+) Streamlit Compatible
